## My Three FL Target Tasks

### 1. Debug React/TypeScript Errors

**Done well means:**
- Identify the actual cause of the error.
- Apply a working fix.
- Confirm the application builds successfully.
- Explain in simple words what caused the problem and how it was fixed.

### 2. Build Frontend Features

**Done well means:**
- The feature matches the requested requirements.
- The UI works on desktop and mobile.
- The code is understandable and maintainable.
- The application builds successfully.
- I understand the code before using it.

### 3. Study Difficult Programming Concepts

**Done well means:**
- The concept is explained in simple language.
- I can answer at least 5 practice questions correctly.
- I can explain the concept without copying the AI response.
- I can apply the concept to at least one example or problem.
