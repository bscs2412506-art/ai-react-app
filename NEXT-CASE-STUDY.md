# How to Add My Next Case Study

## Where it will go

My next case study will go in the Projects / Case Studies section of my portfolio.

I will use the same three-part structure for each case study:

### 1. Problem

Briefly explain the problem the project was solving and why the project was needed.

### 2. What I Did

Explain what I built, the technologies I used, important implementation decisions, and how AI/Claude helped during development.

### 3. What Came of It

Explain the final result, what was completed or deployed, and what I learned from the project.

## Steps to Add the Next Case

1. Create a new case-study entry in the Projects / Case Studies section.
2. Add the project name and a short description.
3. Write the Problem section.
4. Write the What I Did section.
5. Write the What Came of It section.
6. Add relevant links such as the GitHub repository and live deployment.
7. Review the case study for clarity and accuracy.
8. Publish the updated portfolio.
