# React + TypeScript Settings Dashboard

A beginner-friendly modern Settings Dashboard built with React, TypeScript, and Vite.

## Features

- Dashboard page
- Settings page
- Sidebar navigation
- Active navigation links
- Statistics cards
- Settings form
- Name, email, password, and confirm password fields
- Dark mode
- Form validation
- Responsive design for desktop and mobile
- React Router navigation

## Technologies Used

- React
- TypeScript
- Vite
- React Router
- CSS
